# Hospital Operations Analysis

## Overview
This project analyses an unclean hospital operations dataset using SQL to identify and resolve data quality issues before exploring operational performance.

## Objectives
- Assess data quality
- Clean and standardise the dataset
- Explore operational trends using SQL
- Build dashboards in Power BI
- Document the complete analytical process

## Tools
- MySQL
- MySQL Workbench
- Git
- GitHub
- Power BI
